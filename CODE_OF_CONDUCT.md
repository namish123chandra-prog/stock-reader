# Code of conduct

## Our goal

Stock Buddy is a learning project. Everyone should feel able to ask a basic
question without being embarrassed.

## Expected behaviour

- Be patient and kind.
- Explain things in simple words.
- Give helpful feedback about the code, not the person.
- Respect different experience levels, languages and backgrounds.
- Do not share another person's private information.

## Not acceptable

- Harassment, insults, or mocking someone for not knowing something.
- Discrimination of any kind.
- Posting secrets, phone numbers, or private portfolio data.
- Spam or deliberately misleading financial claims.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that break
these rules, and may block repeat offenders.

If something feels unsafe, contact the maintainer through the repository's
Security tab or a private GitHub message.
